# 壁纸模式评审记录（DSH 设计评审）

评审方：shenzhou 上的 DSH（DeepSeek Harness，headless）+ 设计专家包。两轮往返。
结论：前两版用「半透明纸」换照片可见度这条路，方向就是错的；第三版改成**几何让位**。

## 一、前两版为什么不对（DSH 诊断，我逐条复核过）

| # | 问题 | 证据 |
| --- | --- | --- |
| 1 | 壁纸层错用 32px 缩略图铺满屏 | `applyWp()` 算了 `src` 却没用，CSS 写的是 `url(thumb)` |
| 2 | 双重/三重模糊 | `filter: blur()` + `#wp-veil` 全屏覆盖 + 纸面 `backdrop-filter: 26px` |
| 3 | 照片被降级成"材质" | 换一张差异极大的照片，屏幕上几乎看不出区别 |
| 4 | **空解区间** | 纸 84% 时看不出照片；纸 60% 时亮部 11px 文字实测 2.43:1。60–84 之间无解 |
| 5 | 本体论冲突 | 账簿的纸不透光；半透明纸是亚克力，不是纸 |
| 6 | 手机 cover 裁切 | 16:9 照片 cover 进 390×844 只剩中间约 27% 宽 |

## 二、第三版的结构（A″：单缝版）

- **照片**：`cover` 铺满视口，原片，**不模糊、不缩放、不加遮罩**。
- **纸**：不透明、直角、无阴影，**左/上/下三边出血**到视口边缘，只有右侧一条缝。
  宽度 `clamp(750px, 60vw, 900px)`；缝 = 1px 纸色阶差线（−12 L*）+ 内侧 1px 浅档（−3 L*）。
- **顶栏/侧栏**：退进纸里当书眉与栏列，**绝不压在照片上**，也不再半透明。
- **窄屏（≤1099）**：竖窗放不下 → 顶部一条出血图版带（`min(34vh, 56.25vw)`），
  纸在下面按文档流接住，书眉落在纸顶。
- 删掉四个滑块：模糊、遮罩浓度、纸张通透度、玻璃档 —— 它们都在降低照片的信息量。

## 三、验收标准（W1–W7，可量）

| | 规则 | 阈值 | 第三版实测 |
| --- | --- | --- | --- |
| W1 | 照片可见区是单一连通区 | 8-连通不断开 | ✅ 右侧一整块 |
| W2 | 触碰 ≥2 条视口边，其中一条 ≥80% 长度 | 出血 = 不是卡片 | ✅ 上/右/下三边 |
| W3 | 照片区 ≥95% 像素与源片误差 ΔE00 ≤ 2；区内无 blur / backdrop-filter / 半透明覆盖 | 0 层 | ✅ blur 0 个、backdrop 0 个、veil `display:none` |
| W4 | 面积 ≥ 25% 视口 | 防"发丝" | ✅ 40.1%（1254×620） |
| W5 | 换两张差异大的照片，非纸区 median ΔE00 ≥ 8 | 换图一眼可辨 | ✅ 照片区平均差 146.55/255，纸面 0.00 |
| W6 | 至少一维 ≥85% 视口 | 挡掉横向窄条 | ✅ 高 100% |
| W7 | 每个滚动位置仍满足 W1–W4 | 一直能看到 | ⚠️ 桌面版照片固定不动（满足）；窄屏是图版带（滚过即消失，属 B′ 退化形态） |

## 四、没采纳的建议

- **把 UI 切成多块"墨板"**（DSH 的原方案 A）：账簿的核心用法是**一行行扫过去**，
  切碎了行扫描就断了 → 改成单张窄纸 A″。
- **≥55% 照片面积**（DSH 原条款）：与「一屏看完的读数页」冲突（视口 1240×620 时纸面
  只剩 45%，装不下 644px 的内容）。DSH 第二轮自行撤回，换成 W1–W7 拓扑判据。
- **C 方案（桌面段 100vh + 工作段纯纸）**：要重做一屏构图与两套裁切，收益是 W5 已满足的指标。

## 五、第四版（用户澄清后的最终形态）

用户原话：**「我想要的其实就是桌面图标以及文字浮在壁纸的上方」**；之前那句"屏风"
指的是别把照片挡住，不是要一块纸。第三版（照片让出右侧竖窗 + 左边一张纸）
把屏风挪到了右边，本质还是在挡。

第四版：
- 照片 `cover` 铺满整块屏幕，原片。
- 面板**全透明**：顶栏、侧栏、内容区、卡片一律 transparent，只剩 1px 线与文字。
- 可读性靠两件东西（不再靠遮挡）：
  ① `--wp-veil` 很淡的全屏纸色（默认 28%，可拖 0–70%）
  ② 壁纸模式下换墨色：`--ink` / `--v-theme-on-surface` 全翻白 + 三段文字投影
     （桌面壁纸放图标标签的同一套做法）；浮层恢复纸色深墨
- 图表 canvas 拿不到 CSS token → `chartTheme` 里判 `data-wallpaper`，轴标签转白。
- 代价（已在 UI 里说明）：照片的**近白区域**（如太阳、雪地）上白字仍会掉到 1.5:1，
  这是"字直接压在任意照片上"的固有代价；解法是把「文字保护」滑块往上拖。
